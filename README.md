A Python program (standard library only) that draws one piece of original art — HokiiDoge, a Shiba astronaut adrift in a vivid purple-orange nebula with a ringed planet and stars — and writes it to entry.png as a hand-encoded PNG. Deterministic: every run produces byte-identical output.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
